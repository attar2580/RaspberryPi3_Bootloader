RASPBERRY PI 3 SYSTEM BOOT FLOW :

[Power Applied]
       │
       ▼
[GPU: SoC ROM] ───────────▶ Wakes up. ARM CPU is held in hardware reset.
       │                    Mounts the FAT32 partition on the SD card.
       ▼
[GPU: bootcode.bin] ──────▶ Loaded into GPU L2 Cache. 
       │                    Initializes the main 1GB SDRAM.
       ▼
[GPU: start.elf] ─────────▶ Loaded into the newly enabled SDRAM.
       │                    Reads `config.txt` (sets clock speeds, etc.).
       ▼
[GPU: kernel8.img] ───────▶ The raw bootloader payload is read from the SD card.
       │                    Copied byte-for-byte into RAM at physical address `0x80000`.
       ▼
[The Handoff] ─────────▶    GPU toggles the hardware reset line for the ARM CPU.
       │                    Points the CPU's Program Counter to `0x80000`.
       ▼
[CPU: Assembly Startup] ──▶ All 4 cores wake up simultaneously.
       │                    Core 0 reads `mpidr_el1` and takes charge.
       │                    Cores 1, 2, and 3 are parked in an infinite sleep loop.
       │                    Core 0 sets the Stack Pointer (`SP`) just below `0x80000`.
       ▼
[CPU: C Environment] ─────▶ Core 0 branches (`bl`) to your C `main()` function.
       │                    Initializes memory-mapped peripherals (like the Mini UART).
       ▼
